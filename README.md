# LUMORA Naturals & My Portfolio

Welcome to my project! This is a **practice project** where I built a modern, premium frontend landing page for **LUMORA Naturals**—a conceptual, sustainable, clean-ingredient oral care brand. I also paired it with my own custom Full-Stack Developer portfolio page to showcase my work and skills. 

## Features

* **Interactive UI:** I designed custom cursor tracking and trailing ring effects tailored to the brand's aesthetic.
* **Dynamic Animations:** I implemented infinite, continuous-scrolling CSS marquees for smooth section dividers.
* **Scroll-Triggered Reveals:** I used the Intersection Observer API to create smooth fade-up animations and staggered element reveals as you scroll down the page.
* **Multi-Page Experience:** 
  * `index.html`: The primary practice landing page I built for the brand.
  * `sandy.html`: My dedicated developer portfolio page showcasing my projects, skills, and experience.
* **Fully Responsive:** I optimized the entire site to ensure a seamless user experience across all devices (mobile, tablet, and desktop).

## Tech Stack

Here is what I used to bring this project to life:

* **Structure:** Semantic HTML5
* **Styling:** CSS3 (Custom Variables, Flexbox, Grid, Keyframe Animations)
* **Interactivity:** Vanilla JavaScript (DOM manipulation, Event Listeners)
* **Typography & Icons:** Google Fonts (Anton, Manrope, Playfair Display) & FontAwesome 6.5
